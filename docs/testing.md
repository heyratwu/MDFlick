# 项目验证

```sh
CGO_ENABLED=0 go test ./...
go tool mygo vet .
go test -race ./...
bash scripts/test-macos-bridge.sh
```

最后一项需要 macOS、Go CGO 与 Xcode Command Line Tools。脚本在临时目录构建当前 Go 静态库和 C 头文件，再链接 Swift 测试程序，执行后删除临时产物；同时对扩展控制器与桥接适配器进行类型检查。它不安装应用、不注册 Finder 扩展。

## 共享文档行为

`internal/document/policy.go` 定义稳定的校验错误码、中文文案和 Mermaid 判定；`display.go` 定义两个展示端的资源/链接能力与标题锚点命名。`internal/testfixtures` 提供两端共用的 Markdown 样例；原生测试经过实际 MyGo 代码块分发，HTML 测试检查代码块标记、脚本授权以及主动内容过滤。覆盖中文、表格、任务列表、反引号和波浪线围栏、嵌套引用、普通单词、其他语言、未闭合围栏和大小写差异。

`internal/testfixtures.ResourceCases` 是两端共用的地址能力矩阵。原生测试在正文、HTML 对齐段落、表格中实际点击链接，验证表格跳到正文标题、标题引用和标题锚点与 MyGo 的兼容性；Quick Look 测试检查地址过滤、标题 ID、重复标题和导航判定。两端的展示差异见 README 中的能力表，共享规则不要求生成相同布局。

## 异步生命周期

会话测试验证旧成功/错误不能覆盖新文档、关闭后拒绝发布。图表服务测试验证重复请求只提交一次、结果只经 UI 调度器发布、关闭后的回调不能恢复缓存、重复结果不能重复计费；后端测试覆盖队列容量、排队到期、worker 串行执行及取消后退出。

文档预处理测试验证对齐区间、表格引用和 Mermaid 元数据随同一版本发布，旧版本与关闭后的结果不能覆盖当前快照。布局测试显式准备文档，保留居中、标题锚点、宽表格及深浅色回归检查。

图片测试验证重新加载会更换 Options 与图片内容，并检查取消与大小限制；使用本地 HTTP 测试服务器验证网络 PNG、无扩展名 SVG、重定向、错误响应、流式超限及请求中途取消。图片存储测试验证并发去重、本地路径和 URL fragment 归一化、文档与应用预算、地址数量上限、解码失败回收、重复关闭、全局并发限制和等待任务取消；原生视图测试覆盖正文、HTML 对齐段落、表格共用图片，以及同内容重新载入时更换缓存与文档视图状态。预算统计活动文档缓存，取消或关闭时归还；实际对象与 GPU 纹理由框架和 GC 回收，瞬时进程占用可能高于该估算。

新增回归测试覆盖应用加载槽位等待取消与后续任务恢复、图表 worker 共享执行槽位、跨服务缓存预算与重复关闭回收；原生输入/转换后块数及转换输出超限，以及解析/HTML/inline 阶段取消后不返回部分文档。HTML token 遍历用确定性的取消 context 验证处理中断。

原生预处理不再生成独立 Markdown 片段。引用契约直接比较准备后的完整解析文档与原始解析结果的实际 HTML，覆盖折叠/快捷引用、图片、链接内图片、转义标签、多行标题、实体及重复定义，并检查大量无关引用不会引起源码扩展。新增解析采用测试验证视图使用同一解析指针、首帧与后续帧不重新生成已预热的 inline、文档替换不保留旧段落；会话在重载和关闭时释放旧解析文档的所有权。跨块选择测试从对齐正文全选并复制，检查标题、表格与普通正文均包含在同一次复制中，Markdown 复制保留格式。

首屏诊断测试验证正文提交只记录一次，加载/关闭状态不计作正文首屏。实际原生运行已用普通文档及长文/表格/对齐/本地多图的四窗口场景检查事件与资源预算归还；定时结束进程只用于诊断冒烟验证，不代表逐个关窗后 RSS 回落验证。复现入口和测量边界见 [性能验证](performance.md)。框架补丁和依赖更新方式见 [MyGo 本地补丁](mygo-patches.md)。

## Swift/C/Go 所有权约定

- `MDPreviewRender` / `MDPreviewRenderRequest` 在调用期间借用输入；零字节允许 NULL，正字节不允许 NULL。Go 校验后持有自有字符串，返回后不再借用 Swift 数据。
- 必须传入输出槽；每次调用先清空该槽。返回 0 时得到 C 分配的 UTF-8 字符串，其余返回稳定的 `document.Code`。
- 输出字符串与 `MDPreviewErrorMessage` 的字符串均通过 `MDPreviewFree` 释放；NULL 可安全释放。
- `MDPreviewMaxSize` 是 Swift 文件读取上限的来源。Swift 读取最多上限加一字节，将超限和编码错误交给 Go 统一识别。
- `MDPreviewNewRequest` 返回整数句柄；`CancelRequest` 可跨线程取消；`ReleaseRequest` 取消并删除请求，可重复调用。句柄不是 Go 指针。
- `MDPreviewRequestStatus` 返回当前错误码；失效句柄返回 5。新增稳定错误码：8 资源限制、9 取消、10 超时；0–7 保持不变。

桥接测试覆盖空输入、负长度、超限、无效指针组合、失败输出清空、非法 UTF-8、BOM/中文、重复分配与释放、Swift NSError 映射、取消请求不生成输出、失效句柄、句柄重复释放、取消后新请求成功及导航策略。C 输出字符串的重复释放不属于 API 合约。

Go 测试通过阶段观察器在每个渲染阶段后确定性地取消，检查不再进入后续阶段、没有半份输出；并验证输出大小、解析块数和图表数量限制，以及多线程取消请求句柄。性能命令和当前基线见 [性能验证](performance.md)，所有权关系见 [项目架构](project-architecture.md)。

Quick Look DOM 优化另有回归测试，检查删除危险子树后相邻节点仍保留、html/body 包装移除、事件/样式/原始 ID/资源地址过滤、checkbox 强制只读、重复标题和图片替代文字参与锚点命名、仅生成的 Mermaid class 保留、外来内容整棵子树删除。精确预算测试覆盖正文与内置脚本共享的最终输出大小；序列化中途取消必须返回空结果。优化时还将共享功能/性能语料及畸形 HTML 样例与修改前实现逐字节对照，结果一致。

## 仍需手动验证

自动化测试不覆盖实际 WKWebView 的布局与 Mermaid 执行、Finder 扩展注册、窗口关闭动画和系统主题切换。发布前应在安装后的应用及 Finder 中打开 `docs/examples/mermaid.md`，检查图表、错误回退、主题切换，并快速切换多个预览文件。
